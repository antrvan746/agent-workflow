# Changelog

- 2026-11-27: optional docs management. New `wf-docs` skill (`init` / `sync` / `memory`), off unless the profile has a `## Docs` section. Living docs (overview, onboarding, glossary, 9-section module docs with `code:` / `synced:`) vs timeline docs (immutable ADRs with `modules:`, plans under `<root>/plans/active|archive`, change fragments in `<root>/_changes/`, merged and deleted by sync: towncrier pattern). Sync checks the code (code wins, mismatches reported) and ends with agent-memory clean-up (M-lines, per-line approval, backup first); `wf-docs memory` also works with docs off. Presentation levels: 0 = Markdown + Mermaid, Docusaurus-compatible (default, no question); 1 = Docusaurus site (default engine) + interactive API reference; 2 = MDX components + LikeC4/Structurizr; >0 only with the user's OK. Wiring: wf-plan reads module docs/ADRs and saves Hard plans, wf-execute writes fragments/ADRs, wf-verify `DOC-FRAGMENT [should]`, wf-reviewer `missing` fragment, wf-project-init offers it, report `Docs:` line. `wf-lint`: `[docs]` (pending fragments, modules without docs, dead `code:` globs, missing/stale `synced:`, broken links) and `[memory]` (MEMORY.md index vs files) lines; the SessionStart hook suggests `wf-docs` for those and `wf-audit` for the rest.
- 2026-11-27: wf-docs, from dogfooding on a large Java repo. Optional i18n (`locales: en, vi`): first locale is the source sync checks against the code; translations in `<root>/_i18n/<locale>/docusaurus-plugin-content-docs/current/` with `translated_from:`, anchors kept as `{#id}` on translated headings, missing pages fall back to the source; wf-lint flags stale and orphaned translations and resolves translated links through the source page. Writing rules: short statements, one idea per bullet, flows as numbered steps + diagram, decisions as ADRs; ADR template rewritten (Decision, Context, Options table, How it works diagram, Consequences, Guardrails); module template flows/invariants in that style. Level 1 notes (site in `website/`, `@mermaid-js/layout-elk` required, `localeDropdown`); links leaving `<root>` use repository URLs. Init/sync/memory clarified (root choice, keep-in-place docs, grouped I-lines, `adr-index.md`, `commits:` in fragments, `unfragmented` changes, plan `**Status:**`, declined levels recorded, timestamped memory backups). wf-lint: trailing-slash globs match their directory (also fixes Risk map paths), git checks skip instead of misreporting when the time budget is spent, `modules:` accepts values without backticks, a docs summary line in check mode.

- 2026-11-27: stronger reviewer. `wf-reviewer` gains a blind pass (declarations read only after its own findings), an approach check first (`APPROACH:` line), context beyond the diff with `missing`-change findings, a scope check (drive-by edits, mixed refactors, leftovers), a code-health lens (over-engineering, reuse, names, why-comments, consistency), finding categories, an explicit verdict rule and a re-review mode. WORKFLOW.md Reviewer: re-review the fix diff after blocker/major fixes, at most 2 rounds.

- 2026-11-14: evidence and lean tests. WORKFLOW.md Transparency gains "Read the code" (behavior claims need the code read or run; comments, specs, docs and commit messages are hints, `[inferred]` at most; code wins over docs, mismatches are declared, never "fixed" silently). `wf-verify` gains `TEST-REUSE [must]` for every new test at any level (needed? extend an existing test first, fit the project's supported test structure, no kept temporary tests, ask when unsure).
- 2026-11-09: staying up to date. `bin/wf-lint` (deterministic drift/staleness checks, `--global`, `--hook`), SessionStart hook installed by install.sh, `wf-audit` skill (review → D-lines → apply approved or `lint-ignore`), profile `reviewed:` / `audit:` / `lint-ignore:` lines. wf-lint reports only certain problems (unverifiable commands are skipped).
